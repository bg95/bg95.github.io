AIAA3072 — Week 12: Surface Codes and Spacetime Decoding

1. Extract the whole ZIP into a new folder.
2. Open index.html in a modern browser.
3. Follow the eight learning sections, ending with the threshold result.

No server, installation, account, or internet connection is needed.
Keep the six files together. This is a separate Week 12 webpage;
it does not require Week 11 files. No lecture-note PDF or source is included.

Experiments 01 and 02 introduce the local checks and the general Pauli-check circuit.
Click the dashed time lines directly on the measurement circuit to inspect its states.
Experiment 03A shows why one qubit fault is an edge joining the checks it flips.
Move the fault on the same nine-qubit patch and compare X and Z errors.
In 03B, each physical qubit cycles I -> X -> Y -> Z -> I; both check families respond.
The syndrome-graph view shows the Z component (Z and Y sites). Clicking an edge
toggles only that component. Use "Decode this error" to carry the pattern into 04A.

Experiment 03C is a 7x7 playground with two synchronized drawings of the same
49-qubit code. The left puts qubits on nodes and checks in faces; the right puts
qubits on edges, X checks on nodes and Z checks in faces. Click a qubit in either
view to cycle I -> X -> Y -> Z -> I. Every flagged check turns red and displays
bit 1 in both views. Click a check to highlight its qubits and see its operator
and measured outcome. Whenever all checks pass, the readout names the logical
action I, X, Y or Z. Logical I means the code state is unaffected, including
when the physical error is a nontrivial stabilizer.
Clear errors and the three example presets are available.
The sidebar links directly to "7x7 code playground". On a phone, the drawings
stack and each can scroll sideways. The new section works entirely offline.

Experiment 04A accepts any Pauli error on all nine qubits. Cycle each qubit or
choose an I/X/Y/Z brush. The eight check bits, minimum-weight correction, physical
gates and residual update together. The visible three-step algorithm uses only
the syndrome to choose a correction. In 04B, click a same-syndrome example to
change that same figure while keeping the decoder's correction. Compare harmless
stabilizers with logical X, Y and Z failures. All single-qubit errors recover;
multiple errors may change the logical message despite clearing the checks.
Use the message sliders and cycle diagram to inspect input and recovered states.
Editing an error preserves the selected timeline stage.

Experiment 04C introduces the general matching idea using a separate five-edge
strip. Click its five qubit circles to change any error pattern. The error,
correction and residual rows stay visible together; there are no row-selector
buttons. Open circles identify data qubits consistently across the drawings.

In Experiment 05, click the graph directly. A qubit circle or horizontal edge
toggles a new Z fault before that round; I means no new fault. A vertical edge
or its OK/flip marker toggles a wrong check report in the labelled round.
The record and detection events update immediately. All four example presets
remain available. "Decode this history" sends the same faults to Experiment 06.
In Experiment 06, click the same qubit circles or report markers directly on
the graph. All ten locations remain editable in every graph view; the presets
and assumed error rates remain available. Orange shows the faults you set;
green rails show the decoder's inferred paths. The measured record, matching,
correction gates and logical recovery result update together. Editing a fault
keeps the selected view and rates. The small graph searches all endpoint pairings
exactly. Its final check round preserves the quantum data. Click any candidate
path to preview its violet rails and physical correction without changing the
decoder's selected minimum.
Faults inside the extraction circuit are an optional extension after the core
decoding lesson, collapsed by default.

All diagram buttons support Tab and Enter/Space. Wide graphs, circuits and tables
scroll sideways on smaller screens. Desktop uses a 90% page scale, like Week 11;
mobile sizing is unchanged.
Progress stays in local browser storage; nothing is sent anywhere.

The final topic states the positive memory-threshold result without proof.
Experiment 08 uses published fitted logical errors per cycle, including
reported 1-sigma uncertainties, from Google Quantum AI, Nature 614 (2023),
676-681, DOI: 10.1038/s41586-022-05434-1, Fig. 3 and main text.
Switch between the reported tensor-network and belief-matching decoders.
All values are included offline; opening the source-paper link needs internet.
Each experiment states its modeling assumptions.
