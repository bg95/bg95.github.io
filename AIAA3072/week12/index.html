WHAT THE DECODER’S GRAPH MEANS

A qubit error becomes an edge.

The decoder knows which checks flipped, but not which qubits were faulty. The syndrome graph turns that evidence into a path problem: checks are vertices, and possible qubit errors are edges. Start with one error on the same nine-qubit patch.

A boundary can absorb an endpoint.

In this course’s convention, the left and right rough boundaries absorb Z-chain endpoints, which are X-check defects. The top and bottom smooth boundaries absorb X-chain endpoints, which are Z-check defects.

On the rotated patch, turn each check region into a graph vertex and each data site into a possible fault edge: its vertices are checks, and an edge shows the Z component on the labelled data qubit, present for a Z or Y error. The X component is recorded separately by the Z checks. Clicking an edge toggles only its Z component. A red check means syndrome bit 1, or measured eigenvalue −1.

Why “rough” and “smooth”?

Rough · plaquette boundary

Z strings can end here: an X-check defect is absorbed.

Smooth · site boundary

Dual X strings can end here: a Z-check defect is absorbed.

The names reflect the two cuts in early edge-qubit lattice drawings: plaquette versus site boundaries. The rotated patch keeps the names and endpoint rules; its compass directions can differ. See Dennis et al. (2002), Topological quantum memory, Fig. 5 (arXiv:quant-ph/0110143).

04
SAME EVIDENCE, DIFFERENT LOGICAL ACTION

What does the classical decoder do?

It receives the syndrome and a noise model, then chooses a compatible Pauli correction C. Apply C to the quantum data and test the remaining operation CE, where E is the actual error. The loop ends with the recovered logical state.

05
A CHECK BIT IS NOT A NEW FAULT

What if a check report is wrong?

The ideal recovery loop is complete. Now a reported 1 might come from a data error or a wrong report. Repeat the same checks: 0, 1, 1 suggests a persistent data error; 0, 1, 0 can come from one wrong report. We call these report changes detection events. They are the evidence for extending the decoder into time.

The final comparison is part of the evidence.

A wrong report in round 2 creates its second event at round 3. A persistent data fault instead remains in the terminal parity and creates no new terminal change. Omitting that comparison loses the distinction.

This is a phenomenological noise model: ideal check operations, stochastic data faults, and wrong reports. Faults inside individual gates are left to the optional extension after the decoding lesson. The final check round is ideal and preserves the quantum data. Destructive data readout is a different way to close a record, discussed on slide 51; it would end storage.

FROM EVENTS TO WEIGHTED PATHS

Extend the same decoder across time.

The decoder receives the detection events and a noise model. It connects events to each other or to permitted spatial boundaries. Every event must be accounted for. A time-like edge explains a wrong report and adds no data correction.

THE BRIDGE TO WEEK 13

The decoder needs the right target.

Local checks hide the logical amplitudes. Noisy histories reveal detection events. A decoder uses those events to choose a recovery class. Week 13 asks how learning can improve that inference—and how to evaluate it fairly.

08
PERFORMANCE BELONGS TO AN EXPERIMENT

The memory threshold: the result.

Sufficiently low physical error rates allow arbitrarily reliable logical storage as the code distance grows. This is the final result of the week.

A POSITIVE THRESHOLD EXISTS
p < p₀   ⇒   pL(p, d) → 0 as d → ∞

For some p₀ > 0, increasing distance makes logical failure arbitrarily unlikely at any fixed physical rate below p₀.

Here: square planar codes with one logical qubit and O(d²) data qubits; independent data Pauli components and report flips with local rates at most p; d rounds; known initial code sector and an ideal final nondestructive check round; calibrated minimum-weight decoding in both sectors. pL counts a nontrivial residual logical Pauli per complete memory experiment.

Keep the metric clear

These experimental values are fitted logical errors per cycle, averaged over the tested logical X and Z memories. The theorem above concerns a complete memory experiment under its stated model. Do not substitute one metric for the other, or infer a universal threshold from two code distances.

Reliable storage, with stated assumptions.

The threshold depends on the noise model, decoder and experiment. It does not promise success on every finite-distance shot. This is a quantum-memory result; fault-tolerant logical gates are a later topic. The theorem is stated without proof here. Source: Dennis et al. (2002), Topological quantum memory.

A parity meter can spread a fault.

An ancilla collects a joint check value. Its CNOT direction matters: the ancilla is the target for a Z check and the control for an X check. A fault on that shared ancilla can reach several data qubits.

Why the direction matters

Read a check, preserve its logical amplitudes.

For an incoming check eigenstate S|ψ⟩ = σ|ψ⟩, the ideal circuit gives σ = +1 → bit 0 and σ = −1 → bit 1. The circuit above starts in the code space, so its ideal bit is 0. The selected propagating ancilla fault can leave that very report unchanged while corrupting data; other checks can detect the damage.

Changing the gate order changes the hook’s orientation. A complete fault-tolerant schedule must also coordinate neighboring checks and avoid gate collisions.
