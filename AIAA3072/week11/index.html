02
KEEP THE UNKNOWN AMPLITUDES

Compare. Don’t read.

7 MIN

We cannot read an unknown qubit as if it were a classical bit. A direct computational-basis measurement selects one component and loses its coherence with the other. In the encoded superposition below, reading a data qubit also destroys the entanglement among the three data qubits. We must measure comparisons that reveal the error while preserving the message.

Protect correlations, not three copies.

The encoding sends α|0⟩ + β|1⟩ to α|000⟩ + β|111⟩. For nonzero α and β this is an entangled joint state. Measuring the chosen check ancillas preserves its logical coherence for the correctable errors here. Measurement is not inherently destructive: what matters is which information the measurement distinguishes. A basis-state input is a special case, already definite in that basis.

Why reading the data is different

Reading only the parity ancillas cannot distinguish the two logical components: they produce the same syndrome. Reading a data qubit can distinguish them. This contrast uses the same corrupted encoded state, on separate fresh preparations.

FIRST BUILD THE PHASE-REPETITION ENCODER

Repeat the plus/minus labels.

Z|+⟩ = |−⟩Z|−⟩ = |+⟩|±⟩ = (|0⟩ ± |1⟩)/√2

A phase flip exchanges these labels. Start with the bit encoder Vbit|0⟩ = |000⟩, Vbit|1⟩ = |111⟩, then apply H to each output:

Vph = H⊗3Vbit
|0⟩ → |+++⟩,   |1⟩ → |−−−⟩
α|0⟩ + β|1⟩ → α|+++⟩ + β|−−−⟩

Because HZH = X, a Z error becomes a bit flip after changing back to the computational basis. This code protects against one Z error. A single X can still change the logical relative phase. Shor combines this phase repetition with an inner bit code.

Each joint check has a definite eigenvalue for the chosen Pauli error: +1 → syndrome bit 0; −1 → syndrome bit 1. Here ⟨Sᵢ⟩ equals that definite outcome. Measure the product as a whole, preserving the logical superposition.

These are the TA, TB, TC eigenvalue patterns of the two coherent logical components after your error. Each T flips all three qubits in its block. Measure only the products TATB and TBTC; measuring an individual T would reveal the logical basis value.

Why is Z₄ a valid correction for Z₅?

Z₄ and Z₅ both exchange B₊ and B₋ in block B. Their product Z₄Z₅ leaves every encoded state unchanged: |000⟩ picks up no minus signs and |111⟩ picks up two. These errors have the same action on the code. This is degeneracy; the exact physical error site does not always need to be identified.

How do the outer checks become six-qubit comparisons?

VbitX = (X ⊗ X ⊗ X)Vbit

Both sides send |0⟩ to |111⟩ and |1⟩ to |000⟩. An X on one outer representative becomes a triple X on its inner block. The outer pair checks therefore become TATB and TBTC.

TA has eigenvalue +1 on B₊ and −1 on B₋. Measuring TA alone would reveal the logical basis value. Instead measure the products S₇ = TATB and S₈ = TBTC. Both logical codewords have eigenvalue +1 for these comparisons.

ERRORS NEED NOT BE ALL OR NOTHING

A continuous error.
A discrete syndrome.

6 MIN

The check-eigenvalue rule now explains continuous noise. A small rotation creates a coherent combination of error actions. It is not a hidden coin toss that has already chosen “error” or “no error.” Syndrome measurement distinguishes orthogonal error sectors while preserving the logical information within each sector.

06
CONNECT THE CODE, RECORD, AND RECOVERY

How much information is protected?

SYNTHESIS

The examples preserve one logical qubit. We can now count that freedom, and state what successful recovery must restore.

Independent checks constrain the physical space.

9 − 8 = 1 logical qubitn physical qubits − r independent checks = k logical qubits.
The accepted space has dimension 2n−r = 2.

Products of the chosen checks form the stabilizer group. This dimension rule assumes commuting independent Pauli checks whose group excludes −I. The eight displayed checks satisfy these conditions.

The nine-qubit physical space has dimension 2⁹. Each independent compatible check halves the accepted space. Eight checks leave dimension 2: every superposition of the two Shor codewords remains available.

SYNDROME

Measurements produce an ordered check record s.

DECODER

A classical rule uses s and the noise model to choose Rs.

RECOVERY

Apply Rs to the damaged quantum data.

Recover the logical message.

For a fixed Pauli error E with syndrome s, successful recovery requires

RsE|ψL⟩ = eiγ|ψL⟩   for every logical input

E is the error, Rs the chosen correction, and γ an irrelevant global phase. Z₄ corrects Z₅ because Z₄Z₅ fixes every code state. A nontrivial logical operation also keeps a state inside the code space, but changes its stored information. Try X₄X₅ in the Shor experiment to see why clearing the syndrome is insufficient.

A CRUCIAL DISTINCTION

A zero syndrome means the state passes the checks. It does not prove the message is correct. Stabilizers act trivially on the code; nontrivial logical operators change the message while keeping it inside the code space.

OPTIONAL DETAILS · THE MAIN IDEAS ARE ABOVE
Optional: extend the argument to every single-qubit error
A₅ = aI + bX₅ + cY₅ + dZ₅,   Y₅ = iX₅Z₅

I, X, Y, Z form a basis for every single-qubit operator. Linearity attaches the corresponding syndrome record to each term. X is a bit flip, Z a phase flip, and Y combines both. At q₅ the four records differ, so measurement separates these four sectors. A general noise channel may have several such error operators; the same recovery corrects each one.

Measurement does not always split an error into independent X and Z events. It projects onto syndrome sectors. For example, Z₄ and Z₅ have the same record in the Shor code and their coherent terms stay together. They are nevertheless correctable because they act identically on the code. Arbitrary multi-qubit noise is outside the one-qubit guarantee.

Optional: write the syndrome measurement and recovery as operators
Ps = ∏i ([I + (−1)sᵢSᵢ] / 2)
ℛ(ρ) = ∑s RsPsρPsRs†

The commuting check observables Sᵢ define the projector Ps onto their joint syndrome eigenspace. For input density operator ρ, that outcome has probability Tr(Psρ). The second expression averages the corrected states over the classical syndrome record. These formulas summarize the ancilla measurement and conditional corrections already used in the experiments.

Optional: distance and the [[9, 1, 3]] notation

[[n, k, d]] gives physical qubits, logical qubits, and distance. The distance is the smallest weight of a Pauli operator that preserves the code space but acts nontrivially on the logical information. Shor’s [[9, 1, 3]] code corrects every error on at most ⌊(d − 1)/2⌋ = 1 qubit under ideal recovery. Some higher-weight errors are also harmless or correctable; the distance is a worst-case guarantee.

The three-qubit bit repetition code has quantum distance 1: a single Z is already a logical phase flip. Its bit-flip-only guarantee comes from a restricted noise model.

Optional: the Knill–Laflamme criterion
P Ea†Eb P = Cab P

P projects onto the code space; Ea and Eb are errors from a set we wish to correct; Cab is a scalar independent of the logical message. Exact correction is possible precisely when this holds for every pair. Error branches may overlap (degeneracy is allowed), but that overlap must not depend on which logical state was stored.

Optional: CSS checks and Week 12

A CSS code has generators made only of X and I, or only of Z and I. Shor’s generators have this structure. A binary overlap of even parity makes an X-type and Z-type check commute; in matrix form HXHZT = 0 over binary arithmetic.

Week 12 adds noisy measurements, repeated syndrome extraction, and decoding across time. A single ideal check round is the foundation, not a complete fault-tolerant protocol.

A few ideas to carry forward.

A compact glossary
Physical qubit
A qubit in the hardware register.
Logical qubit
The encoded information; here one two-dimensional degree of freedom.
Code space
The subspace of valid encoded quantum states, including their superpositions.
Ancilla
An auxiliary qubit used to extract a check result.
Syndrome
An ordered record of check outcomes, with +1 ↔ 0 and −1 ↔ 1.
Decoder / recovery
The classical rule choosing a correction / the physical operation implementing it.
Stabilizer / logical operator
An operator acting as identity on the code / an operation on the encoded information that preserves the code space.
X, Z, H, CNOT
X swaps |0⟩ and |1⟩. Z changes the sign of |1⟩. H maps |0⟩, |1⟩ to |+⟩, |−⟩. CNOT flips its target if its control is 1.
